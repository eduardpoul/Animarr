DESIGN SYSTEM · 10-FOOT UI

Animarr TV

The leanback design language for Animarr — a self-hosted anime, donghua, film & series library played from the couch. Remote-first (D-pad), image-light for weak TV silicon, built on Hanken Grotesque + a crimson accent. Every rail, tile and poster is a CSS gradient; only the hero / detail backdrop decodes a photo.

Color & accent

A warm near-black palette so fanart and posters carry the color. Surfaces step up in warmth; text steps down. The accent is a single user-recolorable hue (crimson by default) expressed in OKLCH so every tint — fill, hover, soft, line — stays perceptually even.

Focus & glass

05 · PLAYBACK

Video player

A full-viewport overlay; scrims (not solid bars) carry contrast, auto-hiding after 3s while playing. The leanback redesign makes the control bar and every popup first-class D-pad-focusable — the spec's highest-value TV fix. Two styles: Icons only (default) and Full (chips with labels).

player

HUD — D-pad control bar

body.player-open owns the arrows

Top: Back + centered title block (accent kicker "Now playing · S1 · EP 5" + name). Bottom: a scrub row (current / buffer / played / thumb / duration) then a focusable control row — −10 · Prev · Play · Next · +10 primary, then Volume / Quality / Aspect / Cast / Sync / Audio / CC / Info, Fullscreen far right. ←/→ seek, OK = play/pause, Back closes (flushes progress).

player · up-next

Up-next auto-advance

appears past 90%

A frosted card bottom-right that stays opaque while the HUD fades. Shows only when a next on-disk episode exists and playback crosses 90%. In the last 10s "Play next" appends a live countdown and auto-advances at 0.

06 · SETTINGS

Settings (simplified for TV)

On TV the Profile drawer becomes a full-screen panel of D-pad rows. Only what matters from the couch: profile + appearance + audio + switch profile / sign out. Complex server admin (users, folders, LLM, torrents, parsing) is hidden on TV — it lives on desktop/phone.

settings · appearance

Profile & appearance

↕ move · ↔ change value

Rows change value in place with ← / →; OK opens a picker or fires an action. Theme, accent (5 OKLCH swatches), animated backdrop, player style, and a Data saver toggle (hide backdrops — fewer images for slow TVs). The Profile row opens "Who's watching".
