LOADING STATES

Six loader patterns sized for Animarr's screens. Use the top progress bar for any page-level network activity, the splash on cold boot, skeleton posters for the catalog, the button bar inside primary CTAs, and the identification banner when the LLM queue is working through items.

01 · TOP PROGRESS BAR (page-level)

Indeterminate ribbon, 3 px, accent glow.

Shows automatically whenever any in-flight request is active. Hides 200 ms after the queue empties. Lives in the app shell, above the sidebar/header.

02 · SPLASH

First-load boot screen.

Pulsing brand mark + ring spinner + status line. Fades out once the initial library / config payload resolves. Brand-tinted radial background matches the dark theme.

03 · POSTER SKELETONS

Used while Catalog grid populates.

Match poster dimensions so the layout doesn't shift when real cards arrive. Shimmer sweeps left-to-right.

04 · BUTTON SPINNER

Use inside primary CTAs that trigger async work.

Ring spinner replaces the icon, bottom-edge bar provides additional motion. Button stays the same width to avoid layout shift.

05 · IDENTIFICATION BANNER

When the LLM queue is working through items.

Sits above the Catalog grid (or in Settings → AI/LLM) and shows ambient progress. Pulsing ring around the ✨ icon + slow accent gradient bar + live count. Auto-hides when queue is empty.

For tables / lists waiting on more rows.

Three dots, accent-coloured, staggered animation. Use as a row-placeholder at the bottom of an infinite-scroll list, or inside an empty section that's still resolving.
