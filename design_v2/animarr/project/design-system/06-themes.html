Section 06

Themes

Ten UI personalities, same product. Each swaps typography, palette, geometry and decorative motifs — information design stays identical so you can compare apples-to-apples. In production these are user-selectable themes in Settings → Appearance. Quietude (01) is the canonical baseline used in §03–§05.

06.99Implementation noteAll themes ship as the same component tree — only CSS variables and `body.theme-*` font-family change.

Theme switch

Active theme lives in localStorage.animarr-theme and is mirrored as a class on <html>. Every screen, regardless of form-factor, reacts to the same root flag.

Per-user vs server-wide

Theme is per-user, not per-server. Master can lock theme at the server level (Settings → Appearance) to keep brand consistent in shared spaces (a Plex-like server kiosk).
