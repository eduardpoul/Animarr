02.10LoadersSix patterns for "wait" states. Top-bar for page-level, splash for cold-boot, skeletons for grids, button-spinner for CTAs, LLM banner for the queue, dots for tables.

Top progress bar
.ld-top · page-level
Indeterminate ribbon, 3 px, accent glow. Shows for any in-flight request. Hides 200 ms after queue empties.
Ring spinner
.ld-ring
2 px stroke ring, accent-hi top, 0.9 s linear infinite. Use only when scan is open-ended.
Dots
.ld-dots
Loading torrents from session
For row-placeholder inside tables/lists. Staggered animation at 200 ms offsets.

.ld-btn
Ring replaces icon, bottom-edge bar adds motion. Same width — no layout shift.
