Section 04

TV flow

Animarr on a 10-foot screen. Same product, same nav, same screens — only bigger and focus-friendly. We chose this over a from-scratch "TV redesign" so the brain doesn't have to context-switch between phone and living room.

00Cover 01Foundations 02Components 03Browser 04TV 05Mobile 06Themes 07Onboarding 08Hero variants

04.00Two approachesWe default to A. B is shown for one screen so the trade-offs are visible.

● Recommended · used in §04

A. Desktop, just bigger

Same topbar, same hero, same grid as §03 Browser — only enlarged. 1920×1080. Topbar 78 px (was 54). CTAs 16–18 px. Focus = 3 px ring + scale 1.02–1.04.

  • Pros: zero learning curve, single component tree, every fix lands on every form-factor at once.
  • Cons: can feel "TV-ported" rather than "TV-native". Less imposing on a wall-mounted screen.
Alternative · §04.99 only

B. 10-foot custom

Full TV-shop redesign: 70%-height bleed hero, horizontal rails, no topbar tabs, all-uppercase metadata, 200-px posters.

  • Pros: looks like Netflix / Plex / Jellyfin — meets viewer expectations on a TV.
  • Cons: separate layout to maintain. Edit-mode in §03 doesn't reach it. Anti-DRY.

First-run flows (welcome, server discovery, QR pairing, profile picker, PIN) are common to all 3 form-factors and live in §07 Onboarding.
