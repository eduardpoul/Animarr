Foundations

Tokens are the contract. Every screen in the next three sections is built from these primitives and nothing else — surfaces, text, accent, status, spacing, radii, motion. If a screen reaches outside this list, it's not Animarr.

01.08MotionCalm = patient. Nothing crosses 250ms. Springs allowed only on bottom sheets.

Instant
80ms · linear
Hover color, focus ring, chip selection — never block the eye.
Settled
160ms · cubic-bezier(.2,.7,.3,1)
Tab swap, dropdown open, button press feedback. Default duration.
Considered
240ms · cubic-bezier(.2,.7,.3,1)
Drawer slide-in, sheet slide-up, modal scrim. The longest we go.

Easing curvesthree is the limit

linear
— · — · — · —
Only for opacity crossfades and indeterminate spinners.
out · default
cubic-bezier(.2,.7,.3,1)
Fast departure, soft arrival. Every UI transition unless told otherwise.
spring · sheets
300 stiff · 30 damp
Only the mobile bottom-sheet. Implies "grab handle".
