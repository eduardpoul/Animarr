Flow summary

  1. First boot (any device): Welcome → scan LAN (mDNS) → server list → pick → login.
  2. Saved state: device remembers servers + sessions. Returning user skips Welcome + Discovery, lands on Catalog.
  3. TV login: pairing screen with QR + 6-digit code. Phone (already signed in to the server) scans → confirms.
  4. Add server manually: IP:port OR Tailscale magic-DNS (e.g. animarr.your-tailnet.ts.net). One field, no port-forwarding needed.
  5. Switch user: Profile drawer → tap row → PIN prompt (or skip if no PIN set). PIN is per-user, per-device — set at first login on each device.
  6. Switch server: Profile drawer → SERVER block → tap row → if session exists, switch instantly; else go to login flow for that server.
  7. No PIN: tapping a user row signs in immediately. Master account can have or skip PIN. Other users decide their own.
  8. Empty discovery: friendly empty state + "manual" + "rescan" + GitHub link for bug reports.
